Recursion
---------
1. Method calling itself directly or indirectly.
2. Types of Recursion
    |- Indirect Recursion
      A() -> B() -> C() -> A()
    |- Direct Recursion ****
        A()
        {
            A()
        }
3. Base Case: To stop the recursive calling
4. Direct Recursion
    |- Head Recursion
        |- Recursive statement should be first statement in method
        |- Approach: Bottom Up Approach
    |- Tail Recursion:
        |- Recursive statement should be last statement in method
        |- Approach: Top Down Approach                                                 - show(0) -> Terminate
    |- Tree Recursion
        |- More than one Recursive statement in the method
    |- Nested Recursion
        |- Recursive statement inside another Recursive statement
